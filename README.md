# WORDLINK v0.1.0

친구와 실시간으로 즐기는 독립형 한국어 끝말잇기 웹게임의 첫 MVP입니다. 브라우저에서 실행하며, 방 코드 또는 초대 링크로 친구를 초대할 수 있습니다.

## 포함 기능

- 실시간 방 생성 및 방 코드 참가
- 2~8인 대기실, 방장 권한, 준비 상태
- 턴 제한 시간 10 / 15 / 20 / 30초
- 실시간 턴 진행 및 남은 시간 표시
- 서버 측 단어 사전 검증, 끝 글자 연결 검사, 중복 단어 차단
- 제한 시간 초과 시 탈락 처리
- 플레이어 점수판 및 단어 기록
- 재접속 시 이전 방 복원(방이 아직 유지 중인 경우)
- PC · 모바일 반응형 화면
- 기본 단어 데이터 `data/words.json` 분리
- 닉네임별 고정 아바타 색 (같은 닉네임이면 어느 방·기기에서도 같은 색)
- 이모지 반응 (👍 😂 😮 🔥 👏 😭) — 게임 중·종료 후 화면에 떠오르는 효과, 서버에서 허용 목록 검사와 연타 제한(0.35초)
- 라운드 결과 요약 화면 — 순위, 단어 수, 가장 긴 단어, 가장 빠른 입력, 플레이 시간
- 효과음 on/off — 상단 바 버튼, 설정은 브라우저에 저장 (음원 파일 없이 WebAudio로 합성)

## 실행 방법 (Windows)

1. Node.js LTS를 설치합니다. Node.js 26 LTS를 권장합니다. Node.js 22 이상에서 실행할 수 있습니다.
2. 이 폴더에서 터미널 또는 명령 프롬프트를 엽니다.
3. 다음 명령을 차례로 실행합니다.

```bash
npm install
npm start
```

4. Windows에서는 `start.bat`을 더블클릭해도 됩니다. 첫 실행 때 필요한 패키지를 자동 설치합니다.
5. 브라우저에서 `http://localhost:3000`에 접속합니다.
6. 방을 만들고 방 코드 또는 초대 링크를 친구에게 전달합니다.

개발 중 자동 재시작을 사용하려면 `npm run dev`를 실행합니다. 테스트는 `npm test`, 구문 검사는 `npm run check`입니다.

## 친구와 인터넷으로 플레이하기

`localhost` 주소는 내 컴퓨터에서만 열립니다. 친구가 다른 장소에서 접속하려면 이 프로젝트를 인터넷에서 접근 가능한 Node.js 호스팅(Render, Railway, Fly.io, VPS 등)에 배포해야 합니다.

`render.yaml` 배포 설정 파일도 포함했습니다. Render에서 이 저장소를 Blueprint로 연결하면 기본 서비스 설정을 불러올 수 있습니다.

일반적인 배포 설정은 다음과 같습니다.

- Build command: `npm install`
- Start command: `npm start`
- Runtime: Node.js 26 LTS (또는 22 이상)
- 서비스 유형: 장시간 실행되는 Node.js 웹 서비스 (WebSocket 지원)

정적 웹 호스팅만으로는 이 서버를 실행할 수 없습니다. 서버 프로세스가 계속 실행되고 Socket.IO 연결을 지원하는 서비스를 사용해야 합니다. 무료 호스팅은 절전, 접속 제한, 재시작 시 방 데이터 초기화 등의 제한이 있을 수 있습니다.

같은 Wi-Fi에 연결된 친구라면 다음 방법으로 접속할 수 있습니다.

1. 서버를 실행한 PC에서 명령 프롬프트를 열고 `ipconfig`를 실행합니다.
2. 현재 Wi-Fi 어댑터의 `IPv4 주소`를 확인합니다. 예: `192.168.0.15`
3. 친구는 같은 Wi-Fi에서 `http://192.168.0.15:3000`처럼 해당 주소로 접속합니다.
4. Windows 방화벽에서 Node.js의 개인 네트워크 통신을 허용해야 할 수 있습니다.

## 현재 버전의 규칙

- 2~12글자의 한글 단어만 입력할 수 있습니다.
- 첫 글자와 이전 단어의 마지막 글자가 정확히 일치해야 합니다.
- 두음법칙은 아직 적용하지 않습니다.
- 한 번 사용한 단어는 같은 게임에서 다시 사용할 수 없습니다.
- `data/words.json`에 등록된 단어만 인정합니다.
- 단어 길이 × 10점을 얻습니다.
- 제한 시간 내에 단어를 입력하지 못하면 탈락합니다.

## 사전 데이터에 관해

현재 사전은 바로 테스트할 수 있도록 구성한 초기 단어 모음입니다. 국립국어원 전체 사전이나 상용 끝말잇기 게임의 단어 DB와 동일하지 않으며, 모든 표준어·활용형·전문어를 포함하지 않습니다. 단어를 보강하려면 `data/words.json`에 한글 단어를 추가하면 됩니다. 서버 재시작 후 적용됩니다.

## 알려진 제한 사항

- 방과 게임 기록은 서버 메모리에 저장됩니다. 서버가 재시작되면 진행 중인 방은 사라집니다.
- 계정, 영구 전적, 랭킹, 채팅, 관전자, 방 비밀번호는 아직 구현하지 않았습니다.
- 시작 단어 추천과 막다른 글자 방지 기능은 아직 없습니다.
- 초기 사전은 확장용 기초 데이터이며 정식 출시용 대규모 사전이 아닙니다.
- 공용 서버에 배포하기 전에는 요청 빈도 제한, 관리 도구, 사전 데이터 품질 검증, 운영 로그와 모니터링을 추가하는 것이 좋습니다.
- 현재 실시간 방 상태는 서버 메모리에 있으므로 인스턴스를 여러 개 띄우려면 Socket.IO 어댑터와 공유 저장소가 필요합니다.
