# WORDLINK v0.3.0

친구와 실시간으로 즐기는 독립형 한국어 끝말잇기 웹게임의 첫 MVP입니다. 브라우저에서 실행하며, 방 코드 또는 초대 링크로 친구를 초대할 수 있습니다.

## 포함 기능

- **로비 (v0.3)** — 접속자 목록 · 열린 방 목록 · 로비 채팅 · 내 정보. 아래 '로비와 자유 접속 방' 참고
- 실시간 방 생성 및 방 코드 참가
- 2~8인 대기실, 방장 권한, 준비 상태
- 턴 제한 시간 10 / 15 / 20 / 30초
- 실시간 턴 진행 및 남은 시간 표시
- 서버 측 단어 사전 검증, 끝 글자 연결 검사, 중복 단어 차단
- 제한 시간 초과 시 탈락 처리
- 플레이어 점수판 및 단어 기록
- 재접속 시 이전 방 복원(방이 아직 유지 중인 경우)
- PC · 모바일 반응형 화면
- 기본 단어 데이터 `data/words.json` 분리
- 닉네임별 고정 아바타 색 (같은 닉네임이면 어느 방·기기에서도 같은 색)
- 이모지 반응 (👍 😂 😮 🔥 👏 😭) — 게임 중·종료 후 화면에 떠오르는 효과, 서버에서 허용 목록 검사와 연타 제한(0.35초)
- 라운드 결과 요약 화면 — 순위, 단어 수, 가장 긴 단어, 가장 빠른 입력, 플레이 시간
- **단어 입력 카드** — 차례 카드 바로 아래에 크게 배치. 시작 글자 칩(누르면 입력), 입력 중 실시간 규칙 안내(첫 글자·중복·미션 보너스), 오류 시 흔들림 + 인라인 메시지, 다른 사람의 반응으로 화면이 갱신돼도 쓰던 글자 유지
- 효과음 on/off — 상단 바 버튼, 설정은 브라우저에 저장 (음원 파일 없이 WebAudio로 합성)

## 도우미 복구 🐶

화면 구석에 앉아 있는 강아지 마스코트 **복구**가 게임 상황에 맞춰 말을 걸어 줍니다. (Office 길잡이처럼 눌러서 도움말을 볼 수도 있어요.)

- **상황별 반응**: 내 차례(두음법칙으로 쓸 수 있는 글자 안내) · 미션 글자 성공 · 긴 단어·체인 칭찬 · 시간 5초 이하 경고 · 라운드 시작/종료 · 탈락 위로 · 우승 축하
- **오류 풀이**: 단어가 거부되면 이유를 쉬운 말로 설명합니다. (사전에 없음 · 이미 사용함 · 한방 단어 금지 · 첫 글자 불일치와 두음법칙) 같은 이유는 12초에 한 번만 말합니다.
- **도움말 메뉴**: 복구를 누르면 기본 규칙 · 두음법칙 · 점수 계산 · 미션 글자 · 라운드와 탈락 · 한방 단어 · 기능 안내를 볼 수 있습니다. (Esc로 닫기)
- **조절**: 메뉴 아래의 `말 줄이기`(부를 때와 오류 풀이만 말함) · `자리 바꾸기`(왼쪽/오른쪽) · `숨기기`(🐾 버튼으로 다시 부르기). 설정은 브라우저에 저장됩니다(`wordlink.bokgu.v1`).
- 내 차례에는 방해하지 않도록 팁을 말하지 않고, 아무 일 없이 오래 두면 졸아요. `prefers-reduced-motion` 설정을 따릅니다.
- 구성: `mascot.js`(캐릭터 · 말풍선 · 메뉴 · 반응 로직) + `mascot.css`. `client.js`는 `window.Bokgu?.…` 훅만 호출하므로, 두 파일과 `index.html`의 연결 두 줄을 지우면 복구만 깔끔히 빠집니다. 문구는 `mascot.js` 위쪽의 `TOPICS` · `TIPS`에서 고칠 수 있습니다.

## 실행 방법 (Windows)

1. Node.js LTS를 설치합니다. Node.js 26 LTS를 권장합니다. Node.js 22 이상에서 실행할 수 있습니다.
2. 이 폴더에서 터미널 또는 명령 프롬프트를 엽니다.
3. 다음 명령을 차례로 실행합니다.

```bash
npm install
npm start
```

4. Windows에서는 `start.bat`을 더블클릭해도 됩니다. 첫 실행 때 필요한 패키지를 자동 설치합니다.
5. 브라우저에서 `http://localhost:3000`에 접속합니다.
6. 방을 만들고 방 코드 또는 초대 링크를 친구에게 전달합니다.

개발 중 자동 재시작을 사용하려면 `npm run dev`를 실행합니다. 테스트는 `npm test`, 구문 검사는 `npm run check`입니다.

## 친구와 인터넷으로 플레이하기

`localhost` 주소는 내 컴퓨터에서만 열립니다. 친구가 다른 장소에서 접속하려면 이 프로젝트를 인터넷에서 접근 가능한 Node.js 호스팅(Render, Railway, Fly.io, VPS 등)에 배포해야 합니다.

`render.yaml` 배포 설정 파일도 포함했습니다. Render에서 이 저장소를 Blueprint로 연결하면 기본 서비스 설정을 불러올 수 있습니다.

일반적인 배포 설정은 다음과 같습니다.

- Build command: `npm install`
- Start command: `npm start`
- Runtime: Node.js 26 LTS (또는 22 이상)
- 서비스 유형: 장시간 실행되는 Node.js 웹 서비스 (WebSocket 지원)

정적 웹 호스팅만으로는 이 서버를 실행할 수 없습니다. 서버 프로세스가 계속 실행되고 Socket.IO 연결을 지원하는 서비스를 사용해야 합니다. 무료 호스팅은 절전, 접속 제한, 재시작 시 방 데이터 초기화 등의 제한이 있을 수 있습니다.

같은 Wi-Fi에 연결된 친구라면 다음 방법으로 접속할 수 있습니다.

1. 서버를 실행한 PC에서 명령 프롬프트를 열고 `ipconfig`를 실행합니다.
2. 현재 Wi-Fi 어댑터의 `IPv4 주소`를 확인합니다. 예: `192.168.0.15`
3. 친구는 같은 Wi-Fi에서 `http://192.168.0.15:3000`처럼 해당 주소로 접속합니다.
4. Windows 방화벽에서 Node.js의 개인 네트워크 통신을 허용해야 할 수 있습니다.

## 로비와 자유 접속 방 (v0.3)

닉네임을 입력하고 **로비 입장**을 누르면 로비 화면으로 들어갑니다. 방 코드를 몰라도 열려 있는 방을 눌러 바로 참가할 수 있습니다.

- **접속자 목록**: 지금 접속 중인 사람과 위치(로비 / 대기실 N번 / 게임중 N번). 최대 200명까지 표시합니다.
- **방 목록**: 방 번호 · 제목 · 규칙(라운드 수·라운드 시간·턴 시간) · 방장 · 인원 · 상태(대기중 / 게임중 / 가득 참) · 잠금 여부. 카드를 누르면 바로 입장합니다. '입장 가능한 방만' 필터가 있습니다.
- **방 만들기**: 제목, 비밀번호(선택, 영문·숫자 1~8자), 최대 인원, 라운드 수, 라운드 총 시간, 턴 제한 시간, 한방 단어 허용/금지를 정합니다. 만든 방은 목록에 바로 올라갑니다. 방 제목, 비밀번호, 한방 단어 설정은 대기실에서 방장이 바꿀 수 있습니다.
- **비밀번호 방**: 🔒 방은 비밀번호를 맞춰야 입장합니다. 5번 틀리면 30초간 입장이 막힙니다. 이미 그 방의 구성원이었던 사람(재접속)은 비밀번호 없이 돌아올 수 있습니다.
- **빠른 입장**: 잠기지 않았고 자리가 있는 대기 중인 방 중 사람이 가장 많은 방으로 들어갑니다.
- **코드로 입장 / 초대 링크**: 기존 방 코드와 `?room=코드` 초대 링크도 그대로 동작합니다. 링크로 들어오면 닉네임 입력 후 해당 방으로 바로 이동합니다.
- **로비 채팅**: 로비에 있는 사람끼리 채팅합니다. 120자 제한, 0.8초 연타 제한, 최근 60개를 서버가 기억합니다. 방 안에 들어가면 로비 채팅은 보이지 않습니다.
- 게임이 시작된 방, 가득 찬 방에는 새로 들어갈 수 없습니다. 방을 나가면 로비로 돌아옵니다.
- 목록에서 종료된 방과 접속자가 없는 방은 숨겨집니다. 모두 접속이 끊긴 방은 10분 뒤 서버에서 정리됩니다.
- 닉네임은 접속 중인 다른 사람과 겹칠 수 없습니다(같은 사람이 다른 탭/기기에서 다시 들어오는 것은 허용).
- 화면이 좁은 모바일에서는 한 화면에 맞추기 위해 접속자·내 정보 패널을 숨기고 방 목록과 채팅만 보여 줍니다.

### 서버 이벤트 (Socket.IO)

| 이벤트 | 방향 | 설명 |
| --- | --- | --- |
| `lobby:enter` / `lobby:leave` / `lobby:refresh` | 클라 → 서버 | 로비 입장·퇴장·목록 새로고침 |
| `lobby:chat` | 양방향 | 채팅 전송 / 새 메시지 수신 |
| `lobby:rooms` / `lobby:users` | 서버 → 클라 | 방 목록·접속자 목록 갱신 (0.3초 단위로 묶어서 전송) |
| `room:create` | 클라 → 서버 | `title`, `password`, `maxPlayers`, `rounds`, `totalSeconds`, `turnSeconds`, `allowOneShot` 지원 |
| `room:settings` | 클라 → 서버 | 방장 전용(대기실). `allowOneShot`(true/false)을 포함한 방 설정 변경 |
| `room:join` | 클라 → 서버 | `password` 지원. 실패 코드: `PASSWORD_REQUIRED` · `PASSWORD_WRONG` · `PASSWORD_BLOCKED` · `STARTED` · `FULL` |
| `room:quick` | 클라 → 서버 | 빠른 입장 |

비밀번호와 `playerId`는 목록·스냅샷·채팅으로 절대 내보내지 않습니다. (`playerId`는 방에 재접속할 때 쓰는 인증 정보입니다.)

## 현재 버전의 규칙

- 2~12글자의 한글 단어만 입력할 수 있습니다.
- 첫 글자와 이전 단어의 마지막 글자가 정확히 일치해야 합니다.
- 두음법칙을 적용합니다. 이전 단어가 ‘리’로 끝나면 ‘리’ 또는 ‘이’, ‘라’로 끝나면 ‘라’ 또는 ‘나’, ‘녀’로 끝나면 ‘녀’ 또는 ‘여’로 시작하는 단어를 입력할 수 있습니다. (ㄹ·ㄴ + ㅑ ㅕ ㅛ ㅠ ㅣ → ㅇ, ㄹ + ㅏ ㅐ ㅗ ㅚ ㅜ ㅡ → ㄴ, 받침은 유지)
- 한 번 사용한 단어는 같은 게임에서 다시 사용할 수 없습니다.
- `data/words.json`에 등록된 단어만 인정합니다.
- 단어를 낼 때마다 점수를 얻습니다. (아래 '점수 계산' 참고)
- 제한 시간 내에 단어를 입력하지 못하면 **그 라운드에서** 탈락합니다. (다음 라운드에는 다시 참가)

### 한방 단어 허용/금지

- **한방 단어**란 사전에 이어 갈 단어가 하나도 없는 단어입니다. (끝 글자와 두음법칙 변형으로 시작하는 다른 단어가 없음 — 예: 가돌리늄)
- 방장이 방을 만들 때, 또는 대기실에서 **허용 / 금지**를 고릅니다. 기본값은 **허용**이라 기존 동작과 같습니다.
- **금지**로 하면 한방 단어를 내려는 시도는 서버에서 거부되고(`ONESHOT`), 턴과 제한 시간은 그대로 유지됩니다.
- 판정은 사전 기준이며 서버 시작 시 첫 글자별 단어 수를 미리 계산합니다. (`game-rules.js`의 `buildStartIndex()` · `isOneShotWord()`)
- 금지된 방은 로비 목록에 `한방 금지`로 표시됩니다.

### 라운드제 (v0.2)

- 한 경기는 3 / 5 / 7라운드 중 방장이 고른 수만큼 진행됩니다.
- 방장이 **라운드 총 시간**을 20 / 40 / 60 / 80 / 100 / 150 / 500초 중에서 고릅니다. 이 시간이 끝나면 라운드가 끝나고, 생존자 중 라운드 점수가 가장 높은 사람이 라운드를 이깁니다. (동점이면 무승부)
- 총 시간이 끝나기 전에 마지막 한 명만 남으면 그 사람이 라운드를 이깁니다.
- **라운드가 지날수록 턴 제한 시간이 줄어듭니다.** 라운드마다 약 13%씩 줄고 최소 5초입니다. (15초 설정 → 15, 13, 11, 9, 7, 5, 5초)
- 라운드 사이에는 6초 휴식이 있고, 단어 사슬·미션 글자·시작 순서가 새로 바뀝니다.
- 가장 많은 라운드를 이긴 사람이 최종 우승, 승수가 같으면 총점이 높은 사람이 우승합니다.

### 점수 계산

```
점수 = 반올림[ (미션 수 + 2) × (7 × 단어 길이 + 5)^0.74 + 0.88 × 체인 × (남은 시간 비율 + 1) ]
```

- **미션 수**: 단어 안에 미션 글자가 들어간 횟수 (없으면 0)
- **단어 길이**: 단어의 글자 수
- **체인**: 이번 라운드에서 지금까지 나온 단어 수 (이번 단어 포함)
- **남은 시간 비율**: 이번 턴 제한 시간 중 남은 비율 (0~1)
- 구현은 `game-rules.js`의 `calcScore()`에 있습니다.

### 미션 글자 (v0.2)

- 라운드마다 미션 글자가 하나 정해지고, 화면 왼쪽 `MISSION` 칸에 표시됩니다.
- 미션 글자가 들어간 단어(위치 상관없음)를 내면 점수 공식의 미션 수가 늘어 더 높은 점수를 받습니다. 단어 기록에는 `🎯×N`으로 표시됩니다.
- 사전에서 너무 흔하거나 너무 드문 글자는 후보에서 제외됩니다.
- **미션 글자가 사용되면 같은 라운드 안에서도 즉시 새 미션 글자로 바뀝니다.** (방금 쓴 글자는 제외, 모든 플레이어에게 알림 표시)

### 디자인

- 플레이 화면은 규칙 설명 없이 간결하게 구성했습니다. 점수판은 작은 카드 한 줄입니다.
- 밝은 초록 체크무늬 배경 + 나무 보드 + 둥근 카드 스타일의 테마입니다. 스타일은 `styles.css` 맨 아래 `BRIGHT THEME` 블록에 모여 있으며, 이 블록을 지우면 이전 다크 테마로 돌아갑니다.

## 사전 데이터에 관해

현재 사전은 바로 테스트할 수 있도록 구성한 초기 단어 모음입니다. 국립국어원 전체 사전이나 상용 끝말잇기 게임의 단어 DB와 동일하지 않으며, 모든 표준어·활용형·전문어를 포함하지 않습니다. 단어를 보강하려면 `data/words.json`에 한글 단어를 추가하면 됩니다. 서버 재시작 후 적용됩니다.

## 알려진 제한 사항

- 방과 게임 기록은 서버 메모리에 저장됩니다. 서버가 재시작되면 진행 중인 방은 사라집니다.
- 계정, 영구 전적, 랭킹, 관전자, 방 안 채팅은 아직 구현하지 않았습니다. (로비 채팅과 방 비밀번호는 v0.3에서 추가됨)
- 로비 접속자·채팅 기록도 서버 메모리에 있으므로 서버가 재시작되면 사라집니다. 클라이언트는 재연결 시 자동으로 로비에 다시 들어갑니다.
- 시작 단어 추천과 막다른 글자 방지 기능은 아직 없습니다.
- 초기 사전은 확장용 기초 데이터이며 정식 출시용 대규모 사전이 아닙니다.
- 공용 서버에 배포하기 전에는 요청 빈도 제한, 관리 도구, 사전 데이터 품질 검증, 운영 로그와 모니터링을 추가하는 것이 좋습니다.
- 현재 실시간 방 상태는 서버 메모리에 있으므로 인스턴스를 여러 개 띄우려면 Socket.IO 어댑터와 공유 저장소가 필요합니다.
